# 에러 코드

중앙 관리: `errors.cjs`의 `ErrorCode`. 렌더러는 `{ ok:false, code, message }`의 `message`(한국어)를 토스트로 보여 주고 `code`로 후속 동작(탐지 재실행 등)을 정한다.

| 코드 | 계층 | 뜻 | 사용자 메시지 | 후속 동작 |
| --- | --- | --- | --- | --- |
| `ERR_PROMPT_INVALID` | 요청 검증 | 질문이 비었거나 30,000자 초과 | 질문은 1~30,000자여야 합니다. | - |
| `ERR_BACKEND_UNKNOWN` | 요청 검증 | 레지스트리에 없는 백엔드 id | 알 수 없는 AI 연결 방식입니다. | 선택기 새로 고침 |
| `ERR_BACKEND_NOT_INSTALLED` | 비즈니스 | CLI 실행 파일을 찾지 못함 | {이름}이(가) 설치되어 있지 않습니다. 설치 방법: {힌트} | 탐지 재실행 |
| `ERR_BACKEND_LOGIN_REQUIRED` | 비즈니스 | CLI가 로그인되어 있지 않음 | {이름}에 로그인이 필요합니다. 터미널에서 {명령}을 실행해 주세요. | 탐지 재실행 |
| `ERR_BACKEND_BUSY` | 비즈니스 | 이전 요청 진행 중 | 이전 답변을 기다리고 있습니다. | - |
| `ERR_BACKEND_RATE_LIMIT` | 비즈니스 | 사용량 한도 도달 | {이름} 사용량 한도에 도달했습니다. 잠시 후 다시 시도하세요. | - |
| `ERR_BACKEND_TIMEOUT` | 인프라 | 180초 내 응답 없음 | 답변 대기 시간(180초)이 초과되었습니다. | 프로세스 종료 |
| `ERR_BACKEND_CANCELLED` | 비즈니스 | 사용자가 취소 | 답변 수신을 취소했습니다. | - |
| `ERR_BACKEND_FAILED` | 인프라 | 그 외 실패(종료 코드 ≠ 0, 파싱 실패) | {이름} 호출에 실패했습니다: {요약} | 탐지 재실행 |
| `ERR_BRIDGE_DRAFT` | 비즈니스 | Claude 데스크톱 입력창에 초안 존재(화면 자동화) | Claude 입력창에 보내지 않은 초안 “…”이(가) 있습니다. | - |
| `ERR_BRIDGE_FAILED` | 인프라 | 화면 자동화 실패 | (bridge.ps1의 한국어 메시지 그대로) | - |

로그 레벨: 요청 검증·비즈니스 계층은 `warn`, 인프라 계층은 `error`. 로그 형식은 `"[원인 요약]: {}"`, 예: `"백엔드 호출 실패: codex-cli exit 1"`.
