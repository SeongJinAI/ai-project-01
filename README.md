# Orbit — 데스크톱 브레인스토밍 도구

보라색 망토를 두른 검은 고양이를 클릭하면 망토가 고양이 위치에서 화면 전체로 펼쳐지고 마인드맵 카드가 나타나는 Electron 데모입니다. 카드의 질문은 이미 로그인된 Codex CLI나 Claude Code CLI로 보내고 답변을 카드에 채웁니다. 접을 때는 고양이 쪽으로 다시 걷힙니다. 웹 서버나 별도의 AI API 키를 사용하지 않습니다.

## 실행

권장/지원 설치 환경: Node.js 22.12 이상. 현재 환경의 Node 20에서는 실행 테스트를 별도로 확인했습니다.

```sh
npm install
npm start
```

WSL에서 `npm start`를 실행하면 Windows PowerShell을 통해 `%LOCALAPPDATA%\OrbitDemo`에 앱 파일과 Windows용 Electron을 설치하고 **Windows 네이티브 창**으로 실행합니다. Windows에 Node.js/npm이 필요하며 최초 실행에는 다운로드 시간이 걸립니다. 바탕화면의 `Orbit` 바로가기로도 실행할 수 있습니다. WSL GUI 테스트를 원할 때만 `npm start -- --linux`를 사용하세요.

- 실행하면 화면 중앙에 고양이가 나타납니다. 다시 실행하면 고양이를 중앙으로 가져옵니다. 작업 표시줄에서 `Orbit · 망토 고양이`를 찾을 수 있습니다.
- Linux에서 설정된 D-Bus 소켓이 없으면 실행기가 `dbus-run-session`으로 세션을 생성합니다(설치되어 있는 경우).
- 고양이 클릭: 캔버스 열기/접기. 고양이 위 `⠿ ORBIT`를 잡아 위치 이동.
- `Ctrl+Shift+Space` (macOS: `Cmd+Shift+Space`): 열기/접기. `Esc`: 접기.
- `Ctrl`(macOS: `Cmd`)을 누른 채 빈 공간 드래그: 선택한 카드에서 이어지는 질문 카드 생성(그린 사각형 크기가 카드 크기). `질문 그리기` 도구를 켜면 Ctrl 없이 드래그만으로 만듭니다. `새 주제`: 독립된 중심 주제 생성.
- 빈 공간 드래그 또는 마우스 휠(트랙패드 두 손가락): 화면 이동. `Ctrl`+휠: 커서 기준 확대·축소(40~160%).
- 카드 제목 입력 후 `Enter` 또는 `탐색하기`: 예시 답변. `Shift+Enter`: 줄바꿈.
- 카드 제목·답변·카드 안 빈 공간 드래그: 카드 이동. 제목 클릭: 편집(편집 중에는 글자 선택 가능).
- 카드 오른쪽 아래 손잡이 드래그: 카드 너비(220~720px)와 답변 영역 높이(80~900px) 조절. 손잡이 더블클릭: 기본 크기로 복원. 제목은 줄 수에 맞게 자동으로 늘어나고, `질문 그리기`로 큰 사각형을 그리면 그 높이가 답변 영역에 반영됩니다. 크기는 지도에 저장됩니다.
- `Ctrl+W` (macOS: `Cmd+W`): 선택한 카드 삭제. 카드가 선택되지 않으면 창을 닫지 않습니다.
- `Ctrl+C` (macOS: `Cmd+C`): 선택한 카드의 질문과 답변을 텍스트로 복사. 글자를 선택한 경우 선택한 글자만 복사합니다.
- `가지 잇기`: 연결 질문 생성. `⌖`: 카드 전체 보기.
- 지도는 로컬 저장되며 다음 실행에 복원됩니다. 고양이 오른쪽 위 ×로 종료합니다.

## 고양이 조작

- 고양이 몸을 포인터로 잡고 드래그하면 창이 이동합니다. 클릭과 이동은 구분됩니다.
- 아래 − / ＋ 또는 고양이 위 마우스 휠로 60~220% 크기를 조절합니다. 크기는 다음 실행에도 유지됩니다.
- 클릭하면 팔과 망토를 뒤로 당겼다가 앞으로 던지고, 망토가 화면을 덮으며 카드가 나타납니다.
- 여러 모니터에서는 고양이가 위치한 모니터에 캔버스가 열립니다.
- 고양이 머리 위에 시스템 시간(`HH:MM`)이 표시되며 매 분 갱신됩니다. 시계를 클릭하면 알람 패널이 열립니다.

## 알람과 비행

- 시각을 입력하고 `설정`을 누르면 다음에 그 시각이 되는 때(오늘 또는 내일)에 울립니다. `+5분` / `+30분` / `+1시간`으로 지금부터 잡을 수도 있습니다. 메모(20자), `매일 반복`, `알림 소리`(파일 없이 합성한 3음)를 함께 설정합니다.
- 알람은 한 개만 두며 로컬에 저장되어 다시 실행해도 유지됩니다. 패널에 `오늘 07:30 (42분 후) · 회의 · 매일`처럼 남은 시간이 표시되고, 시계 옆에 `⏰ 07:30` 배지가 붙습니다. `해제`로 지웁니다.
- 알람 시각이 되면 고양이가 슈퍼맨처럼 진행 방향으로 몸을 눕혀 가장 가까운 모서리로 올라간 뒤 화면을 대각선으로 가로지르고(X자), 제자리로 돌아옵니다. 모니터가 여러 대면 모든 모니터를 합친 영역을 가로질러 모니터를 넘나듭니다. 속도는 약 950px/s로 5~16초가 걸립니다.
- 비행 중에는 고양이 창을 옮기지 않고, 모니터마다 하나씩 띄운 투명·클릭 통과 오버레이 창 안에서 고양이만 움직입니다(창을 옮기면 Windows에서 검은 사각형이 비칩니다). 그동안 원래 고양이 창은 제자리에서 투명해지고 드래그·크기 조절·망토 던지기가 잠시 막힙니다. 알람 패널의 `미리보기`로 비행을 바로 재생해 볼 수 있습니다.
- 착지하면 시계가 깜빡이며 `⏰ 07:30 회의`를 표시하고 `확인` / `5분 뒤 다시` 버튼이 나타납니다. 시계를 클릭해도 확인됩니다. 2분 뒤에는 자동으로 조용해집니다.
- 잠자기 등으로 알람 시각을 10분 넘게 지나 깨어난 경우에는 울리지 않고 `놓쳤습니다`로 표시합니다. 반복 알람은 다음 날 같은 시각으로 넘어갑니다.

## AI 연결 (Codex · Claude Code)

헤더의 AI 선택기에는 이 PC에 **설치되고 로그인된 AI만** 나타납니다. Orbit은 앱을 시작할 때와 선택기에 마우스를 올릴 때 설치 상태를 다시 확인합니다.

| 항목 | 필요한 것 | 확인 방법 |
| --- | --- | --- |
| ✦ Codex | [Codex CLI](https://learn.chatgpt.com/docs/cli) 설치 + `codex login`(ChatGPT 계정 또는 API 키) | 선택기에 `✦ Codex · codex-cli 0.154.0`처럼 버전이 붙으면 사용 가능 |
| ✦ Claude Code | [Claude Code CLI](https://claude.com/claude-code) 설치 + 본인 구독 로그인 | `✦ Claude Code · 2.1.275` |
| ⚗ Claude 데스크톱 · 화면 자동화 (실험) | Windows Claude 앱 실행 중 | 앱이 꺼져 있으면 `Claude 앱 실행 필요`로 비활성 |
| ✧ 데모 답변 / ↗ 수동 연결 | 없음 | 항상 사용 가능 |

- **Claude·ChatGPT 데스크톱 앱은 필요하지 않습니다.** CLI 경로는 창을 띄우지 않고 답변을 카드에 바로 채웁니다. Orbit은 API 키나 토큰을 저장하지 않으며, 로그인 여부는 `codex login status` / `claude auth status`의 결과로만 확인합니다.
- CLI는 Windows에 직접 설치돼 있어도 되고 WSL 안에 있어도 됩니다. 실행 중인 WSL 배포판에서 찾으면 `wsl.exe`를 통해 호출합니다. 정지된 배포판을 자동으로 켜지는 않습니다.
- **지도 하나 = 대화 하나**입니다. 카드의 `Codex에 질문`을 누르면 첫 질문은 도입 문장과 부모 카드 흐름을 함께 보내고, 이후 질문은 같은 대화에 이어서 보냅니다. 대화 식별자는 지도에 숨겨 저장되며 채팅 목록·세션 관리 UI는 없습니다. 이어 붙일 대화가 사라졌으면 조용히 새 대화를 만들고 부모 카드 흐름을 다시 보냅니다. 카드를 모두 지우면 대화도 새로 시작합니다.
- **답변은 카드 안에 표시됩니다.** 질문 아래 답변 영역에 채워지고, 기다리는 동안 카드 상단에 `답변 대기 중`, 버튼에 `답변 기다리는 중… n초`가 표시됩니다. `수신 취소`로 중단할 수 있습니다. 한 번에 질문 하나만 처리합니다. Claude·ChatGPT 앱에는 이 대화가 나타나지 않습니다.
- **사용량**: 헤더의 `사용량` 버튼에 선택한 AI의 5시간 창 사용률이 표시됩니다(예: `사용량 · Codex 5h 7% · 주 16%`, 70% 이상이면 노랑, 90% 이상이면 빨강). 버튼을 누르면 Codex와 Claude Code 각각의 5시간 창·주간(7일) 사용률 막대와 초기화 시각, 이 지도에서 쓴 질문 수·토큰, 마지막 답변 정보가 보입니다. Codex 한도는 Codex가 남기는 세션 기록에서, Claude Code 한도는 응답 스트림의 한도 이벤트에서 읽습니다. 답변 아래에도 `Codex · 6.1초 · 토큰 입력 15.7k(캐시 12.2k) · 출력 6`처럼 카드별 소요 시간·토큰이 표시됩니다. 한도 값은 각 AI에 질문을 한 번 보낸 뒤부터 나타납니다.
- **스트리밍**: Claude Code는 답변이 만들어지는 대로 카드에 실시간으로 채워집니다(끝에 `▍` 표시). Codex는 CLI가 최종 답변만 돌려주어 완료 후 한 번에 표시됩니다.
- **속도**: 실측으로 Codex 4.6~8.4초(모델 편차), Claude Code 3.6~4.2초(첫 질문)·2.0초(이어가기)이며 Claude Code는 첫 글자가 약 2초 뒤 나타납니다. Orbit이 더하는 지연은 거의 없고 CLI 기동과 모델 응답 시간입니다. Claude Code는 `--safe-mode`로 플러그인·스킬 로딩을 건너뛰어 기동을 줄였습니다.
- Codex는 읽기 전용 샌드박스와 Orbit 전용 임시 폴더에서 실행되어 파일을 쓰거나 명령을 실행하지 않습니다. Claude Code는 도구 없이 텍스트로만 답합니다.
- 오류는 한국어로 안내합니다. 설치 안 됨 → 설치 방법, 로그인 필요 → 실행할 명령, 사용량 한도 → 잠시 후 재시도, 180초 초과 → 시간 초과. 코드 목록은 [에러 코드 문서](docs/error-codes.md)에 있습니다.

### Claude 데스크톱 화면 자동화 (실험)

Windows Claude 앱에 로그인한 뒤 `⚗ Claude 데스크톱 · 화면 자동화`를 선택하고 `연결 확인`을 누르세요. 질문 카드의 버튼을 누르면 Windows UI Automation이 입력창에 값을 설정하고 전송 버튼을 실행한 뒤, 답변이 완성되면 텍스트를 카드로 가져옵니다. 클립보드나 별도 API 호출은 없습니다. 지금 열린 Claude 대화에 계속 질문하며, 이전 답변을 새 답변으로 착각하지 않도록 전송 전에 마지막 답변을 기억해 둡니다.

Claude 입력창에 보내지 않은 초안이 있으면 전송하지 않고 초안 앞부분을 보여 줍니다(`연결 확인`에서도 미리 알려 줍니다). 앱 UI·언어가 바뀌면 깨질 수 있어 실험 기능으로 유지합니다. 현재 설치된 한국어 Windows Claude 2.2553에서 왕복을 검증했습니다.

상용 배포 채널·수수료와 Claude 자동화 약관에 대한 검토는 [배포·수익화 문서](docs/distribution.md)를 참고하세요.

Electron의 투명 창/항상 위 설정을 사용합니다. 창 관리자에 따라 투명도나 최상위 동작이 달라질 수 있습니다. Linux Wayland에서 위치 제어가 안 되면 `npm start -- --ozone-platform=x11`로 실행하세요. 캔버스를 펼치면 마우스 입력을 받으며, 접으면 작은 고양이 창만 남습니다.

## 검증

`npm test`: Linux/macOS 등 현재 Node 환경의 Electron을 실행해 카드 생성, 답변, `Ctrl+W`/`Ctrl+C` 단축키, 클립보드 연결, 저장 복원, 캔버스 접기, 시계·알람·비행, 그리고 가짜 CLI(`test/fake-cli.cjs`)로 Codex·Claude Code 어댑터의 새 대화·이어가기·재개 실패 복구·사용량 한도 처리를 점검합니다. 실제 CLI나 사용량은 쓰지 않습니다. 그래픽 세션이 필요합니다.

Windows 네이티브 검증: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$(wslpath -w "$PWD/test-windows.ps1")"`. 이 테스트는 별도 임시 프로필의 Windows 앱에서 카드 드래그·`Ctrl+W` 삭제·설치 AI 탐지(WSL의 Codex·Claude Code)·고양이 이동/크기 조절·시계/알람 비행·망토 애니메이션을 확인하며 외부 AI에 전송하지 않습니다. 실행 중 포인터가 이동합니다.
